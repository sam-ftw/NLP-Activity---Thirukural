# NLP Activity - Thirukkural Translation Comparison

Thirukkural is a classical Tamil literary work containing 1,330 couplets. Translating its philosophical and literary meaning into another language presents interesting challenges.
This project explores how human and AI translations differ through a combination of traditional NLP techniques and automated linguistic evaluation.

## Features

- **Lexical Similarity:** Jaccard Similarity, TF-IDF, BLEU and ROUGE.
- **Semantic Similarity:** Sentence-BERT and Cosine Similarity.
- **Readability Analysis:** Flesch Reading Ease, Flesch-Kincaid, Gunning Fog and other readability metrics.
- **Text Analysis:** Word count, vocabulary diversity and average sentence length.
- **Text Comparison:** Identifies common and differing words.
- **Visualizations:** Charts comparing similarity and readability scores.

## Technologies Used

Python, Google Colab, NLTK, Scikit-learn, Sentence Transformers, Textstat, Pandas, Matplotlib and Seaborn.

## How to Run

1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Enter a Thirukkural in Tamil.
4. Enter its professional English translation.
5. Enter an AI-generated English translation.
6. Run the cells to generate comparison metrics and visualizations.

## Objective

To explore the linguistic, semantic and readability differences between human and AI-generated translations of classical Tamil literature using NLP techniques.
